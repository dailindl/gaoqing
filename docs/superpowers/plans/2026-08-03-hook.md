# 书法双钩候选生成模块（M5）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于已选黑白图生成 2–10 个书法双钩候选（§6.2），画布与原图一致，含候选记录与 `hook` CLI（AC-07）。

**Architecture:** 新增 `hook.py`（OpenCV 轮廓策略族：外轮廓 / 全层级轮廓 / Canny / 骨架化）；`models.py` 增加 `HookCandidate`；`cli.py` 增加 `hook` 子命令回写 `records/processing.json`。

**Tech Stack:** Python 3.11（conda env `zgy_hd_py311`）、OpenCV 5.0.0（含 contrib/ximgproc）、numpy、Pillow、pydantic v2、pytest、ruff、mypy、black、isort。

## Global Constraints

- Python 3.11+；所有函数必须有 type hints，docstring 使用 Google 风格（AGENTS.md）。
- 路径操作必须使用 `pathlib.Path`，禁止 `os.path`（AGENTS.md）。
- 双钩输入必须为已选黑白图（REQ §6.2）；输出为白底黑线 PNG，与原图同画布同坐标。
- 每次生成 2–10 个候选，均带候选标识、策略标识、参数、生成时间、路径（REQ §6.2）。
- 运行测试：`conda run --no-capture-output -n zgy_hd_py311 python -m pytest`；质量门禁同前。
- 提交信息关联需求编号（AGENTS.md D3）。

### Task 1: 双钩候选生成（hook.py）

**Files:**
- Modify: `hd_image_system/models.py`（新增 `HookCandidate`）
- Create: `hd_image_system/hook.py`
- Test: `tests/test_hook.py`

**Interfaces:**
- Consumes: 无外部模块（输入为已选黑白图路径）。
- Produces: `generate_hook_candidates(bw_selected_path: Path, dest_dir: Path) -> list[HookCandidate]`；策略族 `HOOK_STRATEGIES`。

- [ ] **Step 1: 写失败测试**（合成实心矩形黑块输入；断言候选数 2–10、同尺寸、二值、白底；轮廓/Canny 策略边缘为黑线、骨架策略中线为黑线）
- [ ] **Step 2: 运行确认失败**
- [ ] **Step 3: 实现**
  - `_contour_hook(ink, hierarchy_mode, thickness)`：findContours + drawContours 白底黑线。
  - `_canny_hook(ink, low, high)`：Canny + 形态学闭合后转黑线。
  - `_skeleton_hook(ink, width)`：`cv2.ximgproc.thinning` + 膨胀重建双钩线。
  - 策略：external_contour×2、all_contours×2、canny×2、skeleton×2，共 8 个。
- [ ] **Step 4: 运行确认通过**
- [ ] **Step 5: 提交**
