# 黑白候选生成模块（M4）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于原图生成 2–10 个黑白候选（§6.1），含印章红色掩码归入前景、极性统一（白底黑字）、候选记录与 `bw` CLI，并提供已选黑白图 master 的质量边界校验（AC-06）。

**Architecture:** 新增 `binarize.py`（策略族：Otsu / 自适应均值 / 自适应高斯 / Sauvola / Wolf，Sauvola/Wolf 用 DoxaPy 0.9.2）；`models.py` 增加 `BWCandidate`/`BwValidation`；`cli.py` 增加 `bw` 子命令回写 `records/processing.json`。

**Tech Stack:** Python 3.11（conda env `zgy_hd_py311`）、OpenCV、DoxaPy 0.9.2、numpy、Pillow、pydantic v2、pytest、ruff、mypy、black、isort。

## Global Constraints

- Python 3.11+；所有函数必须有 type hints，docstring 使用 Google 风格（AGENTS.md）。
- 路径操作必须使用 `pathlib.Path`，禁止 `os.path`（AGENTS.md）。
- 每次生成 2–10 个候选，均带候选标识、策略标识、参数、生成时间、路径（REQ §6.1；AC-05）。
- 已选黑白图必须与原图同画布同坐标；候选输出为二值 PNG（REQ §6.1）。
- 印章必须归入黑色前景；黑底白字来源图必须统一为白底黑字输出（REQ §6.1；AC-06）。
- 0/255 严格二值约束仅限 master PNG（REQ §6.1 澄清，V1.2）。
- 运行测试：`conda run -n zgy_hd_py311 python -m pytest`；质量门禁同 M2/M3。
- 提交信息关联需求编号（AGENTS.md D3）。

    bg = (0, 0, 0) if dark_bg else (255, 255, 255)
    ink = (255, 255, 255) if dark_bg else (0, 0, 0)
    img = Image.new("RGB", size, bg)
