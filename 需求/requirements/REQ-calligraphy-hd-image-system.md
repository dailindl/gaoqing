# 书法高清大图系统完整需求规格书 (V1.0)

## 项目概述

本系统为书法高清大图的数字化展示提供完整解决方案，支持移动端（手机/PAD）流畅查看高清大图，并提供缩略图快速定位功能。系统包含三种图像版本：原图、黑白图、书法双钩图。

### 核心目标
- 在移动端流畅以瓦片图形式查看高清大图
- 提供高清大图缩略图快速定位
- 支持三种图像版本：原图、黑白图、书法双钩图
- 所有文件永久存储，便于后续上传到阿里云 OSS

---

## 一、系统架构

### 1.1 核心组件

本系统采用分离式架构，包含以下独立模块：

```
原始图 → 拼接高清大图 → [三种版本独立生成程序] → 黑白图 + 双钩图 →
三种高清图各自生成瓦片图（严格对应）
```

#### A. 原图瓦片服务系统 (核心 API)
- **职责**: 提供高清大图瓦片化服务和 JSON 接口
- **技术栈**: Python 3.11+, FastAPI
- **环境**: Conda 虚拟环境 `zgy_hd_py311`
- **功能**: 仅负责原图的瓦片化处理和接口服务

#### B. 黑白图生成程序
- **职责**: 从原图生成黑白图（支持多参数变体）
- **参考**: D:\wordspaces\claudeCode\gaoqing\heibai20260630
- **输出**: 2-10 个不同参数的黑白图变体
- **处理**: 人工选择最优结果后生成瓦片图

#### C. 双钩图生成程序
- **职责**: 从选定的黑白图生成双钩图（支持多参数变体）
- **输入**: 人工选定的最优黑白图
- **输出**: 2-10 个不同参数的双钩图变体
- **处理**: 人工选择最优结果后生成瓦片图

#### D. 人工评审界面 (独立工具)
- **职责**: 提供详细对比界面，用于人工选择最优 BW/Hook 结果
- **类型**: 独立 standalone 工具，非核心系统组件
- **功能**: 详细的单图对比，支持缩放、并排比较

### 1.2 数据流

```
输入图像 (JPG/PNG/TIF) → 拼接/处理 → 原图瓦片化
                              ↓
                    [独立程序] 黑白图生成 (多参数变体)
                              ↓
                    [人工评审] 选择最优黑白图
                              ↓
                    [独立程序] 双钩图生成 (多参数变体)
                              ↓
                    [人工评审] 选择最优双钩图
                              ↓
                    三种版本瓦片化 → 统一存储
```

## 四、存储架构

### 4.1 存储原则

- **永久存储**: 所有生成文件（原图、黑白图、双钩图、瓦片图、缩略图）
- **扁平命名**: 便于后续上传到阿里云 OSS 同一文件夹
- **规模**: 支持几千张高清大图

### 4.2 文件命名规范

```
/storage/{img_id}_original.jpg          # 原图
/storage/{img_id}_bw.jpg                # 黑白图（选定后）
/storage/{img_id}_hook.jpg              # 双钩图（选定后）
/storage/{img_id}_thumb_{index}.jpg     # 缩略图（仅原图）
/storage/{img_id}/{z}/{x}_{y}.jpg       # 原图瓦片
/storage/{img_id}_bw/{z}/{x}_{y}.jpg    # 黑白图瓦片
/storage/{img_id}_hook/{z}/{x}_{y}.jpg  # 双钩图瓦片
```

### 4.3 阿里云 OSS 兼容

- 采用扁平化文件结构，避免复杂目录
- 支持批量上传到同一 OSS 文件夹
- 预留云端迁移接口

## 六、瓦片图详细规范

### 6.1 瓦片切割标准

- **瓦片尺寸**: 固定 256×256 像素
- **坐标系**: 左上角原点 (0,0)，X 轴向右递增，Y 轴向下递增
- **金字塔层级**: 从全局缩放的最小图层（Z=0）生成至 1:1 原始分辨率的最底层（Z=Zmax）
- **质量**: 最大值为原始图片，不压缩

### 6.2 三种瓦片图一致性

- **坐标对应**: 三种瓦片图使用相同的 X/Y/Z 坐标系统
- **层级同步**: 所有版本的最大缩放层级相同
- **尺寸一致**: 所有版本的瓦片尺寸严格相同

---

## 七、缩略图规范

### 7.1 生成规则

- **仅原图生成**: 缩略图只基于原图生成，三种版本共用
- **画幅约束**: 严格保持 9:16 宽高比
- **命名排序**: 从右向左，最右侧为阅读起点
- **API 输出**: 按 index 倒序排列

### 7.2 单图模式切分

- **切分步长**: 固定宽度 1080 像素
- **倒序切分**: 从大图最右侧开始，每次向左移动 1080 像素
- **边缘处理**: 最左侧不足 1080 像素时，允许与前一页重叠

### 7.3 多图模式生成

- **一一对应**: 一张原始分屏图对应生成一个缩略图
- **容错截取**: 非 9:16 比例时，以物理中心点向外扩散截取 9:16 中心区域
